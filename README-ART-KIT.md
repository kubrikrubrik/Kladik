# Набор для художника «Царская казна» v2.0

- `ART-BRIEF.md` — стиль, размеры, запросы для генерации, таблицы частей и шарниров.
- `_reference-<персонаж>.png` — общий вид персонажа (векторная разметка, 4× холста). Это не образец стиля, а точная раскладка поз и пропорций.
- `guide-ch-<персонаж>-<часть>.png` — каждая часть отдельно, на полном холсте, в положении покоя. Ваш слой `ch-<персонаж>-<часть>.webp` должен совпасть с ним по месту и силуэту.
- `guide-art-<сцена>.png` — композиция сцены без персонажей; `_reference-<сцена>-with-characters.png` — где стоят персонажи.
- `parts.json` — машиночитаемый список частей, родителей и шарниров.

Все файлы лежат в одной папке, без подпапок.
